# Памятка для Claude

В репозитории два независимых проекта владельца. Общение с владельцем — по-русски, он не программист:
объясняй простыми словами, технические шаги делай сам.

## 1. «Волшебная почта Деда Мороза» — именные видеопоздравления (основной заработок сейчас)

- `studio/` — конвейер: анкета → готовый ролик MP4 (720×1280, ~1,5–2 мин).
- `moroz/` — сайт-витрина с анкетой (GitHub Pages: `…github.io/samokati/moroz/`), настройки в `moroz/config.js`.
- `ЗАПУСК.md` — план продаж, тексты объявлений, ответы клиентам.
- Страница-пульт для владельца (чек-лист и те же тексты с кнопками «Копировать»):
  https://claude.ai/artifact/PyfeASDgaGFp19AeTUL9Nz — меняешь тексты в `ЗАПУСК.md`, обнови и её
  (Artifact: read по ссылке → правка → publish с тем же `url`).

### Когда владелец присылает заказ (анкету клиента)

1. Собери анкету в JSON в `studio/orders/<имя>.json` (образцы: `studio/orders/_пример*.json`,
   все поля описаны в начале `studio/script.py`). Папка `orders/` в git не попадает — так и должно быть.
2. Проверь текст без затрат: `python3 studio/make_video.py studio/orders/<имя>.json --text`.
   Факты должны продолжать фразу «Я знаю, что ты …» (2-е лицо: «научился…», «помогаешь…») — если клиент
   написал иначе («Миша любит рисовать»), перепиши сам. Подарок — в именительном падеже. Исправь опечатки.
3. Собери ролик: `python3 studio/make_video.py studio/orders/<имя>.json` (≈2 минуты).
   Получатся два файла в `studio/out/…/`: `ОБРАЗЕЦ_…mp4` (водяной знак, отправляется клиенту до оплаты)
   и `Дед-Мороз_<имя>.mp4` (чистый, после оплаты). Отправь оба владельцу через SendUserFile.
4. Напомни владельцу прослушать ролик перед отправкой: ты не слышишь звук и не можешь проверить ударение
   в редких именах. Если ударение неверное — поле `name_tts` в анкете задаёт, как произносить имя
   (например, написать с буквой «ё» или иначе по слогам), на плашках останется `name`.
5. Правки текста: любой сегмент можно заменить целиком через поле `script` (список `{scene, text, card}`).
   Озвучка кэшируется в `studio/.cache/tts` — неизменённые фразы повторно кредиты не тратят.

Варианты: `"style": "adult"` — взрослому; `"style": "group"` — одно видео на группу/класс
(`studio/orders/_пример-группа.json`); много детей списком — `python3 studio/batch.py таблица.csv`.
Необычный заказ (корпоратив, «на вы», другой повод) — напиши сценарий руками через `script`.

### Озвучка и доступы

- Основной голос — ElevenLabs, голос «Ivan - New Year Storyteller» (`0vJ96DzHePfGJitmI6UX`, уже добавлен
  в аккаунт владельца), модель `eleven_v4`. Ключ подставляет прокси облачной сессии.
- Остаток кредитов: `GET https://api.elevenlabs.io/v1/user/subscription`. Ролик ≈ 1000 знаков.
  Если кредиты кончаются: `--tts eleven_turbo` или `--tts yandex` (ключ в `YANDEX_SPEECHKIT_API_KEY`,
  голос проще) — и скажи об этом владельцу.
- Картинки/видео сцен сделаны через xAI (`studio/lib/xai.py`), повторно генерировать не нужно:
  готовые клипы лежат в `studio/assets/clips`. Новая сцена = кадр (`xai.image`) → клип (`xai.video_*`),
  это платно для владельца (копейки, но спрашивай, если больше пары долларов).

### Чего нельзя

- Репозиторий публичный: никогда не коммить `studio/orders/`, `studio/out/`, имена, фото и переписку клиентов.
- Не обещай владельцу доход и не выдумывай отзывы, «N довольных клиентов» и т. п. для сайта и объявлений.
- Не рассылай ничего сам от имени владельца (почта, мессенджеры) без его прямой просьбы на конкретное действие.

### Сайт

Правки цен и контактов — только в `moroz/config.js`. Обложки для объявлений пересобираются командой
`node studio/promo/covers.mjs <цена>` (кладёт в `moroz/promo/`). Публикация — workflow
`.github/workflows/deploy.yml` (ветка `gh-pages`); Pages включает владелец в настройках репозитория.
