# Студия: именное видеопоздравление от Деда Мороза

Анкета → готовый ролик за ~2 минуты. Дед Мороз называет ребёнка по имени, хвалит за добрые дела,
даёт наказ, намекает на подарок и передаёт привет от близких.

## Самый простой способ — попросить Claude

Откройте сессию Claude Code в этом репозитории и напишите, например:

> Заказ: Миша, мальчик, 6 лет. Научился кататься на велосипеде, помогает маме, ходит на плавание.
> Наказ — убирать игрушки. Подарок — большой конструктор. Привет от мамы Оли и папы Димы.

Claude соберёт два файла и пришлёт их:

| Файл | Кому | Когда |
|---|---|---|
| `ОБРАЗЕЦ_Дед-Мороз_Миша.mp4` | клиенту | сразу, до оплаты (водяной знак) |
| `Дед-Мороз_Миша.mp4` | клиенту | после оплаты |

Перед отправкой обязательно прослушайте: правильно ли звучит имя.

## Вручную (в терминале)

```bash
# посмотреть текст, ничего не тратя
python3 studio/make_video.py studio/orders/_пример.json --text

# собрать ролик (образец + чистый)
python3 studio/make_video.py studio/orders/_пример.json

# то же без файла анкеты
python3 studio/make_video.py --name Соня --gender f --age 4 \
  --fact "сама одеваешься в садик" --fact "выучила стих про ёлочку" --from "мама и папа"

# одно видео на группу детсада / класс
python3 studio/make_video.py studio/orders/_пример-группа.json

# много детей из таблицы (CSV: name, gender, age, fact1, fact2, fact3, advice, gift, from)
python3 studio/batch.py studio/orders/группа.csv
```

Полезные ключи: `--tts eleven_turbo` (вдвое экономнее), `--tts yandex` (запасной голос),
`--only final` / `--only preview`, `--brand "Заказать: t.me/ваш_ник"` (мелкая подпись в финале),
`--style adult` (поздравление взрослому).

## Анкета

```json
{
  "name": "Миша",
  "gender": "m",
  "age": 6,
  "facts": ["научился кататься на велосипеде", "помогаешь маме накрывать на стол"],
  "advice": "почаще убирай игрушки и вовремя ложись спать",
  "gift": "большой конструктор",
  "from": "мама Оля и папа Дима",
  "photo": "misha.jpg"
}
```

- `facts` продолжают фразу Деда Мороза «Я знаю, что ты …».
- `gift` — только если подарок действительно будет под ёлкой (в именительном падеже).
- `photo` — появится в волшебной книге в золотой рамке.
- `name_tts` — как произносить имя, если голос ошибается в ударении.
- `script` — полностью свой сценарий (см. начало `script.py`).

## Что нужно для работы

`ffmpeg`, Python 3, Node.js с Playwright (Chromium) — в облачной сессии Claude всё это уже есть.
Ключи: ElevenLabs (или `ELEVENLABS_API_KEY`), запасной Yandex SpeechKit (`YANDEX_SPEECHKIT_API_KEY`).

## Из чего сделан ролик

- `assets/clips/` — 7 видеопланов (терем, Дед Мороз ×2, волшебная книга, мастерская, тройка, ёлка);
- `assets/audio/` — музыкальная подложка и эффекты; `assets/fonts/` — шрифты (лицензия OFL);
- `overlays/render.mjs` — именные плашки; `script.py` — текст; `make_video.py` — сборка.

Заказы клиентов (`orders/`) и готовые ролики (`out/`) в репозиторий не попадают.
