# 🛴 PRO SCOOTER SHOP — сайт магазина трюковых самокатов и запчастей

Готовый сайт-каталог. Товары берутся из папки `csd` — точно с такой же структурой,
как у вас на рабочем столе: **имя папки = название модели, внутри фото и текстовый
файл со ссылкой на товар**.

## Как посмотреть сайт

Сайт публикуется автоматически через GitHub Pages по адресу:

**https://andreyrk2016-ctrl.github.io/samokati/**

Если по ссылке ничего не открывается, публикацию нужно включить **один раз**:

1. Откройте репозиторий на GitHub → вкладка **Settings** (Настройки).
2. Слева выберите **Pages**.
3. В пункте **Source** выберите **Deploy from a branch**.
4. В пункте **Branch** выберите ветку **gh-pages**, папку **/ (root)** и нажмите **Save**.

Через минуту-две сайт появится по адресу выше. Дальше всё автоматически:
при каждой загрузке файлов сайт пересобирается сам.

## Как добавить свои товары (папка csd)

1. Откройте репозиторий на GitHub и убедитесь, что выбрана нужная ветка.
2. Нажмите **Add file → Upload files**.
3. Перетащите мышкой **папки с моделями** со своего рабочего стола прямо в окно
   загрузки — так, чтобы они попали внутрь папки `csd` (проще всего: перетащить
   сразу всю папку `csd` в корень репозитория, файлы объединятся).
4. Внизу нажмите зелёную кнопку **Commit changes**.
5. Подождите 1–2 минуты — сайт пересоберётся и покажет ваши товары.

> ⚠️ GitHub принимает не больше 100 файлов за одну загрузку. Если файлов больше —
> загрузите в несколько заходов.
>
> 💡 Пока в `csd` нет товаров, сайт показывает примеры из папки `csd-demo`.
> Как только появятся ваши товары, примеры автоматически пропадут.

### Формат папок

```
csd/
├─ Urban Artt Primo/          ← имя папки = название товара на сайте
│   ├─ фото1.jpg              ← фотографии (jpg, png, webp — любые)
│   ├─ фото2.jpg
│   └─ ссылка.txt             ← текстовый документ со ссылкой на самокат
└─ Запчасти/                  ← подпапка для запчастей (необязательно)
    └─ Колёса 110 мм/
        ├─ фото.jpg
        └─ ссылка.txt
```

### Что можно написать в текстовом файле

Обязательна только ссылка. Остальное — по желанию:

```
https://ссылка-на-товар.com/model
Цена: 349
Описание: Любой текст про товар — покажется в карточке.
```

- **Ссылка** — куда ведёт кнопка «Купить».
- **Цена** — просто число, на сайте покажется в долларах: $349.
- **Описание** — текст в карточке товара.

Если цену не указать, на карточке будет «Цена по запросу».

## Как поменять название магазина и контакты

Откройте файл `index.html` и поменяйте:

- **Название** — найдите `SAMOKATI` (в `<title>`, шапке и подвале).
- **Контакты** — секция `contacts`: телефон `+7 900 000-00-00`,
  телеграм `@username` и почту замените на свои.
- **Письма покупателям** (код при регистрации, «заказ принят») — как
  включить настоящую отправку, написано в файле `ПОЧТА-НАСТРОЙКА.md`.

Изменить файл можно прямо на GitHub: откройте файл → иконка карандаша →
внесите правки → **Commit changes**.

## Как это устроено (для любопытных)

- `index.html`, `styles.css`, `app.js` — сам сайт (без фреймворков, чистый HTML/CSS/JS).
- `build_catalog.py` — скрипт, который сканирует `csd/` и создаёт `catalog.js`
  (список товаров для сайта). Запускается автоматически при каждой загрузке
  файлов (см. `.github/workflows/deploy.yml`), вручную запускать не нужно.
- Локально можно запустить `python3 build_catalog.py` и открыть `index.html`
  в браузере — сайт работает и без сервера.

## Советы

- Фото лучше сжимать до ~1200px по ширине — сайт будет летать.
- Название папки показывается на сайте как есть — пишите красиво: «Urban Artt Primo S2», а не «urban_artt_primo_s2».
- Первым на карточке показывается фото, которое идёт первым по алфавиту — назовите главное фото `1.jpg` или `фото-1.jpg`.
