# Как подключить почту (коды и письма о заказах — покупателям)

Сейчас сайт работает в тестовом режиме: код подтверждения при
регистрации показывается прямо на экране, а письма никому не уходят.

Чтобы письма по-настоящему приходили покупателям — код при регистрации
и «заказ принят» после покупки — подключите бесплатный сервис
**EmailJS**. Он отправляет письма с вашего почтового ящика: до 200
писем в месяц бесплатно, банковская карта не нужна. Займёт ~10 минут.

## Шаг 1. Завести аккаунт EmailJS

1. Откройте **www.emailjs.com** → кнопка **Sign Up**
   (проще всего «Sign up with Google»).
2. Войдите в панель управления (dashboard.emailjs.com).

## Шаг 2. Привязать свой почтовый ящик

С этого ящика будут уходить письма покупателям, и на него же придут
их ответы.

1. Слева **Email Services** → **Add New Service** → выберите **Gmail**.
2. Нажмите **Connect Account** и войдите в свой Google-аккаунт,
   разрешите отправку писем.
3. Нажмите **Create Service**.
4. Запишите **Service ID** из списка сервисов — выглядит как
   `service_ab12cde`.

## Шаг 3. Создать шаблон письма

1. Слева **Email Templates** → **Create New Template**.
2. В поле темы письма (**Subject**) сотрите всё и впишите ровно:
   `{{subject}}`
3. В большом поле с текстом письма (**Content**) сотрите всё и впишите
   ровно: `{{message}}`
4. ⚠️ Самое важное: справа найдите поле **To Email** и впишите в него
   ровно: `{{to_email}}` — без этого письма не будут доходить
   до покупателей.
5. Нажмите **Save**. Запишите **Template ID** — выглядит как
   `template_xy34zw`.

## Шаг 4. Взять публичный ключ

Справа вверху нажмите на своё имя → **Account** → вкладка **General** →
скопируйте **Public Key** (набор букв и цифр).

## Шаг 5. Вписать три ключа в сайт

Проще всего — **пришлите Клоду все три значения** (Service ID,
Template ID, Public Key), он впишет сам. Это публичные ключи, не
пароли — показывать их можно.

Или впишите сами: откройте в репозитории файл `email-config.js`
(иконка карандаша), уберите `//` в начале строк с конфигом и
подставьте свои значения:

```js
window.EMAILJS_CONFIG = {
  serviceId: "service_ab12cde",
  templateId: "template_xy34zw",
  publicKey: "AbCdEfGh123456_"
};
```

Нажмите **Commit changes** — через 1–2 минуты сайт пересоберётся.

## Что изменится после подключения

- Код подтверждения при регистрации придёт покупателю письмом
  (на экране он больше показываться не будет).
- После оформления заказа покупателю придёт письмо «Заказ принят»
  со списком товаров, суммой и адресом доставки.
- Если письмо вдруг не уйдёт (кончился месячный лимит, сбой сервиса) —
  сайт не сломается: код снова покажется на экране, как сейчас.

## Полезно знать

- Первое время письма могут попадать в «Спам» — предупредите
  покупателей проверять эту папку.
- Проверить, что всё работает: зарегистрируйтесь на сайте заново,
  указав свою почту, — код должен прийти письмом, а не показаться
  на экране.
- Предпросмотр сайта в claude.ai всегда остаётся в тестовом режиме
  (там запрещены обращения к внешним сервисам). Настоящие письма
  уходят только с основного сайта на github.io.
- Если позже подключите Firebase (см. FIREBASE-НАСТРОЙКА.md),
  подтверждение почты при регистрации возьмёт на себя Google —
  придёт письмо со ссылкой вместо кода. EmailJS при этом останется
  нужен для писем «заказ принят».
